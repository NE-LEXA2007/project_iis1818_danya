# Практика 3: автомат ролей

Три роли: analyst (0,15, все рубрики), repayment (0,1,
category=early_repayment), penalties (0,05, category=penalties).
Граф — `Orchestrator.TRANSITIONS`; интенты определяются регулярными выражениями,
без обращения к LLM. Незнакомый интент → analyst.

Из repayment нельзя напрямую в penalties и обратно: нужно пройти analyst,
чтобы уточнить состояние задолженности. При запрете route() возвращает analyst
и явно пишет «откат» в лог. Это демонстрационное правило маршрутизации,
а не утверждение о банковском запрете досрочного погашения при просрочке.

Последовательность в одной сессии, проверена автоматическим тестом:

| Фраза | Интент | Роль |
| --- | --- | --- |
| Какая ставка по кредиту? | question | analyst |
| Можно погасить досрочно? | early_repayment | repayment |
| А если погашу раньше срока? | early_repayment | repayment |
| Какая неустойка за просрочку? | penalties | analyst, откат |
| Штраф за опоздание платежа? | penalties | penalties |
| Хочу закрыть кредит досрочно | early_repayment | analyst, откат |
| Если заплачу больше чем надо? | early_repayment | repayment |
| Какие документы нужны? | question | analyst |
| Что значит ПСК? | question | analyst |
| 123 неизвестное | question | analyst |

Проверены перенос найденного контекста при смене роли и вызовы MCP-обёртки.
Публичные сигнатуры и файлы MCP из шаблона сохранены.

Для вопросов на сопоставление добавлена диверсификация по источникам через
search_filtered(source=...). Это устраняет потерю второго документа в обычной
выдаче top-k и проверяется отдельным тестом.
